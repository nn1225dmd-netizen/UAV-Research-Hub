# UAV Research Hub 1.0 — 第一階段基礎版

本工具協助無人機產業研究資料管理。所有研究內容由使用者輸入與核對，不提供 AI 自動生成或對外傳送文件。第一次開啟只有固定索引，沒有任何訪談原文或已確認書目。

## Windows 首次安裝與啟動

1. 將交付 ZIP 解壓縮至可寫入的本機資料夾，例如「文件\UAV-Research-Hub」。請勿直接在 ZIP 中執行。
2. 安裝 python.org 官方 Python 3.10 或更新版本，勾選 Python Launcher（建議 Python 3.12）。
3. 雙擊 `首次安裝.bat`，首次須連網下載免費套件；等候顯示「安裝完成」。
4. 雙擊 `啟動系統.bat`。瀏覽器會開啟繁體中文操作介面。若未自動開啟，依啟動視窗的 Local URL 操作。
5. 操作期間保留啟動視窗。關閉時在該視窗按 Ctrl+C，再關閉視窗。
6. 下次只須雙擊啟動。遇到問題先執行 `環境檢查.bat`，保留畫面訊息；不要提供含內部資料的截圖。

程式預設只監聽本機 127.0.0.1，不提供網路共享；停用 Streamlit 使用統計。首次套件安裝需要網路，資料登錄不需要付費 API。Windows 批次檔已提供，但本次在 Linux 驗證，尚待 Windows 實機驗收。請保留整個資料夾，不要僅複製 app.py。

## 第一次使用

1. 「TW-LOG 文獻資料庫」：選擇索引，按原件補齊正式書目。下方可登錄來源文件並關聯 INT 或 TW-LOG；純訪談文件可取消所有 TW-LOG 選擇。文件唯一編碼是附件管理碼，不是另一套訪談編碼。輸入原件完整路徑會計算 SHA-256，不會搬移原檔。
2. 「廠商與訪談資料庫」：選擇 INT，填寫產業定位及技術方向，另新增訪談日期、摘要、需求、機會與來源附件。下拉選單可選既有訪談修改。編碼與固定廠商對照不可編輯。
3. 「研究證據管理」：選取原始來源，逐字貼入原文並填寫頁碼或段落位置；可複選 KPI、廠商及輸入主題。原文、來源與定位儲存後鎖定，摘要與分類可修改。若原文登錄錯誤，另建正確證據，將舊證據標為「需修正」並註記。
4. 「全站資料搜尋」：可搜尋中文、編碼、廠商，並依日期、主題、KPI、查核狀態篩選研究證據；選擇證據可查看原文與來源路徑。廠商／訪談與文獻索引分區顯示，主題與 KPI 篩選用於證據結果。
5. 「KPI 成果對照」：依契約補正式名稱、目標及判定方式。此版本僅列佐證，沒有自動認定達成數。
6. 「備份、還原及系統設定」：可建立 SQLite 安全備份（僅資料庫），並查看最近操作時間。原始文件必須另行保管與備份。

INT-01～12 的固定廠商對照屬內部資訊。TW-LOG-001～008 的預建提示不是已確認題名。沒有 TW-VISIT 資料表、欄位或搜尋；手動來源登錄如出現歷史 TW-VISIT 會阻擋，請先依原件人工核對 INT，勿依序號推定對應。

## 檔案保存與安全

- `data/hub.sqlite3` 保存資料，`data/backups/` 保存資料庫備份。重新開啟沿用資料庫。
- `data/originals/` 預留原件目錄；第一階段只登錄檔案路徑，並未複製附件。搬動原件會使登錄位置失效。
- 保密等級是管理標記，非存取權限或加密。請使用 Windows 帳號權限與磁碟加密保護整個資料夾。
- 本版沒有公開匯出功能；請勿將畫面或資料庫直接對外提供。
- 需要整體備份時，先關閉系統，再複製整個專案資料夾及所有外部原始文件到安全位置。完整還原精靈尚未實作，勿直接覆寫正在使用的資料庫。
- 資料庫使用版本號，重複初始化不清除資料；未來升級須有先備份的遷移流程。本版拒絕開啟比程式新的結構版本。

## 開發與測試（一般使用者不用操作）

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python check_environment.py
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

測試使用暫存資料庫與匿名內容，不寫入正式 data。可用 `UAV_HUB_DATA` 指定另一個資料目錄。需求檔限定相容主版本，`requirements-tested.txt` 記錄本次驗證的確切套件版本。
